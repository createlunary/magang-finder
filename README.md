# showcase-data

Branch data untuk situs showcase Magang Finder. Berisi satu file, `snapshot.json`,
yang ditulis dan di-push otomatis oleh mesin lokal (`mf.py showcase`) setiap kali
run atau Deep Search selesai. Kode situsnya ada di branch `main`.

Isi: lowongan, skor, alasan penilaian, profil perusahaan, laporan Deep Search,
statistik sumber, angka ringkas run. Tidak ada data pribadi.
